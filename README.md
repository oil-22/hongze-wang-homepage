## Preview

Open `index.html` in a browser. This English-only, responsive website has no build step or external dependencies.

## GitHub Pages

Publish the contents of this directory to the `main` branch of a public GitHub repository. In **Settings → Pages**, choose **Deploy from a branch**, then select **main** and **/ (root)**. Save and wait for deployment.

The `.nojekyll` file allows the page to be served as a static website.

## Editing

Update the text and styles directly in `index.html`. Keep the page title, description, affiliations, and email links in sync with any content changes.

This is a personal website, not an official Zhejiang University website.
